## 关于我

日常开发总爱写很多乱七八糟的东西：想到就动手，东摸西摸。真正要沉下心去学更高深的内容时，又很难坐住。所以长期是这种状态：**什么都懂一点点，什么都不精通**。

但我确实喜欢折腾。桌面程序、小工具、编辑器配置、渲染实验，只要能跑起来、能看见结果，就会继续玩。GitHub 对我来说不是展示墙，是学习笔记和实验场。

到了 AI 这个时代，单纯写代码更难静下心。我现在更常做的是：**把需求讲清楚，给 AI 定好方向，然后让 AI 去搭**。不装自己从零手写完整个系统，装的是知道要什么、敢于让工具协助。

## 现在和未来

| | 现在 | 往哪里去 |
| --- | --- | --- |
| 主线 | Qt / C++ 桌面、工具 / IDE、脚本与配置 | **AI Agent 应用开发** |
| 做法 | 需求自己定，脚手架交给 AI | 把这种协作变成可复用的 Agent 产品 |
| 开源 | 读、fork、本地玩 | 靠近 Linux / FFmpeg 这类项目，也愿意把自己的 Agent 实践留下来 |

未来几年想把功力集中在 **AI Agent 应用**：能真正帮我搞定任务的代理，而不是只会聊天的窗口。桌面工具、编辑器、自动化流程都可以是 Agent 的载体。自己还在入门，但方向已经定下来。

## 在折腾什么

这些项目帮我把 Qt、CMake、渲染和工具链跑通。下一步想把同样的折腾感，用到 Agent：能读仓库、改代码、跑任务的那种应用。

很羡慕那些知识渊博的开发者，能在 **Linux**、**FFmpeg** 这类顶级项目里贡献代码。自己还没走到那一步：更多是读、fork、本地玩。方向不改 —— 继续看、继续学，有机会就往里走近一步。
